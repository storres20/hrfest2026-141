# HRFEST 2026-141 — Plasma Freezer Thermal Analysis

This repository contains the datasets, analysis notebooks, intermediate results,
and figures associated with the paper:

**"High-Resolution Thermal Characterization and Sampling-Interval Assessment of a Hospital Plasma Freezer Using IoT Monitoring"**

submitted to **HRFEST 2026**.

The repository is intended to support the reproducibility of the statistical,
temporal, and sampling-interval analyses reported in the study.

---

## Repository Contents

The repository contains the original monitoring dataset, the processed datasets
corresponding to the two acquisition regimes (G1 and G2), Google Colab notebooks,
derived CSV files, and figures generated during the analysis.

### Original dataset

`bio_data_10mindata_ult26_250926.csv`

Original CSV dataset exported from the IoT monitoring system and used as the
source for the subsequent processing and analysis.

### Processed datasets

- `plasma_G1_1min_FINAL.csv`  
  High-resolution monitoring regime (G1), containing 26,077 observations
  acquired at approximately 1-min intervals over 18.16 days.

- `plasma_G2_10min_FINAL.csv`  
  Operational monitoring regime (G2), acquired at a nominal interval of
  approximately 10 min.

- `transition_G1_G2_FINAL.csv`  
  Data associated with the transition between the G1 and G2 acquisition regimes.

## Sampling-Interval Assessment

The sampling-resolution experiment was performed using the high-resolution G1
dataset. Progressively lower temporal resolutions were generated by retaining
observations at approximately:

- 1 min
- 2 min
- 3 min
- 5 min
- 10 min

The retained observations were evaluated in terms of data-volume reduction and
preservation of global descriptive statistics.

Intermediate observations were reconstructed using linear interpolation, and
reconstruction accuracy was evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Square Error (RMSE)
- 95th-percentile absolute error
- Maximum absolute error

The original acquisition gaps were excluded from reconstruction-error
calculations.

---

## Temporal Analysis

Temporal dependence was investigated using the autocorrelation function (ACF).

Stationarity was assessed before ACF interpretation using:

- Augmented Dickey-Fuller (ADF) test
- Kwiatkowski-Phillips-Schmidt-Shin (KPSS) test

Linear detrending was subsequently applied to the selected continuous segments.

The analysis identified recurrent thermal behavior at approximately 50-min
intervals in both G1 and G2.

This recurrence is interpreted as a **thermal pattern** and not as direct
evidence of compressor cycling because compressor operating state was not
independently recorded.

## Main Dataset Characteristics

| Characteristic | G1 | G2 |
|---|---:|---:|
| Acquisition regime | High resolution | Operational |
| Nominal interval | ~1 min | ~10 min |
| Observations | 26,077 | 1,686 |
| Monitoring duration | 18.16 days | 14.19 days |
| Mean temperature | -30.581 °C | -31.092 °C |
| Median temperature | -30.5 °C | -31.5 °C |
| Standard deviation | 0.680 °C | 0.972 °C |

G1 was used as the controlled reference dataset for evaluating the effect of
temporal subsampling.

G2 represents an independently acquired operational period and was used to
evaluate whether the recurrent thermal structure remained observable under the
approximately 10-min monitoring regime.

Because G1 and G2 correspond to consecutive rather than simultaneous monitoring
periods, differences between their temperature distributions should not be
attributed solely to sampling interval.

## Software

The analyses were developed using **Python** in **Google Colab**.

The Jupyter notebooks (`.ipynb`) included in this repository contain the code
used for data processing, statistical analysis, temporal analysis, sampling
experiments, reconstruction-error calculations, and figure generation.

## Reproducibility

The files in this repository are provided to allow readers to inspect and
reproduce the analyses reported in the paper.

The recommended workflow is:

1. Load the original CSV dataset.
2. Execute the preprocessing notebook.
3. Generate the G1 and G2 datasets.
4. Execute the G1 analysis notebooks.
5. Execute the G2 analysis notebook.
6. Execute the final G1-G2 analysis notebook.
7. Compare the generated CSV results and figures with those reported in the paper.
